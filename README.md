
Library Management System

A web-based library management system designed to streamline book cataloging, member management, and borrowing workflows.

Current Status

• Frontend & UI: Complete and uploaded.
• Backend (PHP): Currently excluded from this repository (in development / pending integration).

Features

• Dashboard: Overview of library statistics, available books, and active loans.
• Book Catalog: Browse, search, and filter books by title, author, or category.
• Member Interface: Clean layout for managing student and staff library accounts.
• Responsive Design: Accessible across desktop and mobile devices.

Tech Stack

• Frontend: HTML5, CSS3, JavaScript
• Styling / UI: (e.g., Bootstrap, Tailwind CSS)
• Planned Backend: PHP & MySQL
